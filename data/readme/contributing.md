## Contributing

Missing a work or disagree with a level? Open an issue or a pull request. The README is generated from [`data/`](data/), so edit [`refs.bib`](data/refs.bib) and [`papers.yaml`](data/papers.yaml) and run `python scripts/build_readme.py`; see [CONTRIBUTING.md](CONTRIBUTING.md). Corrections to † levels are especially welcome.

<sub>{{LINKED}}/{{N}} entries are linked ({{ARXIV}} arXiv, {{DOI}} DOI), matched by exact title against DataCite and Crossref. A flat export is in [`data/catalog.csv`](data/catalog.csv).
